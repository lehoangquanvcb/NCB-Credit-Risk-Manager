# Deployment Guide

1. Unzip this package.
2. Upload all files to GitHub.
3. Go to Streamlit Cloud > New app.
4. Select repository, branch `main`, and set Main file path to `app.py`.
5. Deploy.

## Replace sample data
Replace CSV files in `/data` with the same column names. Start with:
- `loan_portfolio.csv`
- `risk_appetite.csv`
- `limits.csv`
- `policy_rule_engine.csv`
- `external_alerts.csv`
- `macro_scenarios.csv`
- `collateral_haircuts.csv`
- `strategy_scenarios.csv`
- `recovery_triggers.csv`
